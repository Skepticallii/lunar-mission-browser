# Model 1 Outputs

This folder contains CSV outputs generated by the Solar Availability Model.

## Files

### `lm1_horizon.csv`
Contains estimated local terrain horizon angles for 360 azimuth directions, from 0° to 359°. These values are used to estimate whether terrain obstructs the Sun.

### `solar_timeline.csv`
Contains timestamped estimates of sunlight visibility at the selected lunar south-pole candidate location. The model samples the Sun's position at 10-minute intervals.

## Usage
These files can be inspected with Python, spreadsheet software, or data-analysis tools. They are intended for further analysis and potential integration into the Lunar South Pole Mission Planner website.

## Important Notes
- The outputs are preliminary and have not completed full scientific validation.
- Results depend on the input terrain data, coordinate conventions, horizon-search distance, and SPICE calculations.
- These CSV files contain model outputs; the original terrain raster and SPICE kernels are stored separately.
