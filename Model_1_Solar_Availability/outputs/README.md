# Lunar South Pole Mission Planner — Model Outputs

## Overview
This folder contains the generated CSV outputs from the lunar mission planning models. These files provide precomputed data for comparing candidate landing sites near the lunar south pole.

## Files

### 1. `horizon_profiles.csv`
Contains terrain horizon elevation angles for each candidate site at different azimuth directions. This data helps estimate whether the Sun or Earth is blocked by surrounding terrain.

### 2. `visibility_timeline.csv`
Contains hourly sampled Sun and Earth positions and their visibility relative to the terrain horizon at each candidate site. It supports solar availability and Direct-to-Earth (DTE) communication visibility analysis.

### 3. `site_comparison.csv`
Summarizes key visibility statistics for the candidate sites, allowing the website to compare their preliminary solar and communication opportunities.

## Candidate Sites
- LM1 — Shackleton Rim B
- Site06 — Nobile Rim 1
- Site20 — Leibnitz Beta Plateau
- Site23 — Malapert Massif

## Data Notes
- The timeline covers October 15, 2026, to January 12, 2027, at 60-minute sampling intervals.
- Visibility percentages are preliminary estimates based on the generated model outputs.
- Hourly sampling may miss short visibility windows and does not establish exact continuous visibility durations.
- The results require further scientific validation, including independent checks of coordinate reference systems, terrain alignment, and Sun/Earth direction calculations.

## Website Integration
These CSV files are intended to provide precomputed data for website visualizations and candidate-site comparisons. The frontend must use the correct file paths and column names when loading the data.

## Reproducibility
The CSV files are generated by the project's Python model pipeline. Refer to the main project repository for the scripts, configuration, and validation checks required to regenerate and verify these outputs.
